# Models and code generation — recommended approach

Covers `freezed`, `json_serializable` and `build_runner`, and how `riverpod_generator` and `go_router_builder` share the same run.

Sources, read 2026-10-04: [freezed](https://pub.dev/packages/freezed) and its [changelog](https://pub.dev/packages/freezed/changelog), [json_serializable](https://pub.dev/packages/json_serializable), [build_runner](https://pub.dev/packages/build_runner) and its [changelog](https://pub.dev/packages/build_runner/changelog).

Versions documented: `freezed 4.0.2`, `freezed_annotation 3.1.0`, `json_serializable 6.14.1`, `json_annotation 4.12.0`, `build_runner 2.16.1`.

**Docs** marks what the documentation states; **Recommendation** marks my reading of it. Code samples have not been compiled.

---

## 1. Decisions to make once

| Decision | Recommendation | What the docs say |
|---|---|---|
| Model classes | `@freezed`, with `fromJson` generated by json_serializable. | Freezed generates `==`, `hashCode`, `toString`, `copyWith`; JSON comes from json_serializable when a `fromJson` factory is present. |
| Class keyword | `abstract class` for a data class, `sealed class` for a union. | Since 3.0 the class must be `abstract` or `sealed`. |
| Branching on unions | Dart `switch`. | `when` and `map` were removed in 3.0. |
| JSON options | Set them once in `build.yaml`, not per class. | Precedence is `@JsonKey` > `@JsonSerializable` > `build.yaml`. |
| Generated files | Commit them. | "You may choose whether to commit generated files." |
| One pipeline | A single `build_runner` runs all four generators. | — |

## 2. Setup

```yaml
dependencies:
  freezed_annotation: ^3.1.0
  json_annotation: ^4.12.0

dev_dependencies:
  build_runner: ^2.16.1
  freezed: ^4.0.2
  json_serializable: ^6.14.1
```

`json_serializable 6.14.1` requires `json_annotation >=4.12.0 <4.13.0`. `freezed 4.0.2` requires analyzer 14.

```yaml
# build.yaml
targets:
  $default:
    builders:
      json_serializable:
        options:
          explicit_to_json: true
          # field_rename: snake     # if the API uses snake_case keys
          # include_if_null: false  # if the API rejects nulls
```

`explicit_to_json: true` makes `toJson` call `toJson` on nested models. Without it nested Freezed objects are left as objects in the map.

```yaml
# analysis_options.yaml
analyzer:
  errors:
    invalid_annotation_target: ignore   # allows @JsonKey on Freezed parameters
```

## 3. A data class

```dart
import 'package:freezed_annotation/freezed_annotation.dart';

part 'event.freezed.dart';
part 'event.g.dart';

@freezed
abstract class Event with _$Event {
  const factory Event({
    required int id,
    required String title,
    DateTime? startsAt,
    @Default(false) bool isFavorite,
    @JsonKey(name: 'organizer_name') String? organizer,
  }) = _Event;

  factory Event.fromJson(Map<String, dynamic> json) => _$EventFromJson(json);
}
```

```dart
final updated = event.copyWith(isFavorite: true);
final renamed = company.copyWith.director(name: 'Jane'); // deep copy
```

- `toJson` is generated automatically once `fromJson` exists.
- `List`, `Map` and `Set` fields are unmodifiable by default.
- To add getters or methods, add a private constructor: `const Event._();`.
- Doc comments and annotations placed on a constructor parameter are copied to the field.

## 4. A union

```dart
@freezed
sealed class AppException with _$AppException implements Exception {
  const factory AppException.noConnection() = NoConnection;
  const factory AppException.timeout() = RequestTimeout;
  const factory AppException.cancelled() = Cancelled;
  const factory AppException.server(int? statusCode, [String? message]) =
      ServerError;
  const factory AppException.unknown(Object? cause) = UnknownError;
}
```

```dart
final text = switch (error) {
  NoConnection() => l10n.errorNoConnection,
  RequestTimeout() => l10n.errorTimeout,
  ServerError(:final message?) => message,
  ServerError() => l10n.errorServer,
  Cancelled() || UnknownError() => l10n.errorUnknown,
};
```

The compiler reports a missing case. Only properties shared by every constructor can be read without a `switch`.

For unions that are decoded from JSON, Freezed uses a `runtimeType` key by default; change it with `@Freezed(unionKey: 'type')` and `@FreezedUnionValue('...')`.

## 5. JSON details

**Enums**

```dart
enum EventStatus {
  @JsonValue('open') open,
  @JsonValue('closed') closed,
  unknown,
}

@JsonKey(unknownEnumValue: EventStatus.unknown) required EventStatus status,
```

**Recommendation:** give every enum that comes from the server an `unknown` value. A new value added on the backend then does not crash older app versions.

**Custom conversion**

```dart
class EpochDateTimeConverter implements JsonConverter<DateTime, int> {
  const EpochDateTimeConverter();

  @override
  DateTime fromJson(int json) => DateTime.fromMillisecondsSinceEpoch(json);

  @override
  int toJson(DateTime object) => object.millisecondsSinceEpoch;
}

@EpochDateTimeConverter() required DateTime createdAt,
```

**Generic wrappers** (paged responses)

```dart
@Freezed(genericArgumentFactories: true)
abstract class Paged<T> with _$Paged<T> {
  const factory Paged({required List<T> data, required int lastPage}) = _Paged;

  factory Paged.fromJson(
    Map<String, dynamic> json,
    T Function(Object?) fromJsonT,
  ) => _$PagedFromJson(json, fromJsonT);
}
```

Supported field types without a converter: `BigInt`, `bool`, `DateTime`, `double`, `Duration`, `Enum`, `int`, `Iterable`, `List`, `Map`, `num`, `Object`, `Record`, `Set`, `String`, `Uri`.

## 6. Running the generator

```bash
dart run build_runner watch -d
```

```bash
dart run build_runner build -d
```

`watch` regenerates on save and is the mode to leave running while developing.

What changed in recent `build_runner` releases:

- 2.14: builders are AOT-compiled by default and incremental builds are about twice as fast.
- 2.15: `--low-resources-mode` and the performance-tracking flags are ignored.
- 2.16: generated files that are wrong on disk are fixed automatically. `--only-check` writes nothing and reports whether the files on disk are up to date.

Limit a builder to the folders that need it; this is the cheapest speed-up on a large project:

```yaml
targets:
  $default:
    builders:
      json_serializable:
        generate_for:
          - lib/**/models/*.dart
```

### Other generators in the same run

| Annotation | Package | Output |
|---|---|---|
| `@freezed` | `freezed` | `x.freezed.dart` |
| `@JsonSerializable`, Freezed `fromJson` | `json_serializable` | `x.g.dart` |
| `@riverpod` | `riverpod_generator` | `x.g.dart` |
| `@TypedGoRoute` | `go_router_builder` | `x.g.dart` |

A file needs one `part 'x.g.dart';` however many of these it uses. See [riverpod-guide.md](riverpod-guide.md) and [go-router-guide.md](go-router-guide.md).

## 7. Generated files in git

**Recommendation:** commit `*.g.dart` and `*.freezed.dart`, and run the `--only-check` build in CI. A fresh clone then runs without a generation step, and CI fails if someone forgot to regenerate. Never edit generated files; add `.dart_tool/` to `.gitignore`.

The alternative, ignoring them and generating in CI, is equally valid. Pick one policy for all generated code, including the localization files.

---

## 8. Things that changed recently

- **Freezed 4.0:** the `final` keyword inside a constructor parameter is no longer supported. Dart primary constructors are supported.
- **Freezed 3.0:** `when`/`map` removed; classes must be `abstract` or `sealed`; a plain class with ordinary fields can also be annotated ("mixed mode").
- Dart 3.13 has primary constructors in the language. Freezed is still what provides `==`, `copyWith` and unions.

---

## 9. Review checklist

- [ ] Models are immutable `@freezed` classes; no hand-written `==` or `copyWith`.
- [ ] Unions are `sealed` and consumed with `switch`.
- [ ] JSON options live in `build.yaml`; `explicit_to_json` is on.
- [ ] Server enums have an `unknown` fallback.
- [ ] No manual edits in generated files.
- [ ] Generated files follow one policy: all committed, or all ignored.
- [ ] CI runs the generator check.
